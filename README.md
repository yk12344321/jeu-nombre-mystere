# jeu-nombre-mystere

Présentation

Jeu développé en Python dans lequel le joueur doit deviner un nombre généré aléatoirement par l'ordinateur.

Fonctionnalités

- Génération aléatoire d'un nombre.
- Trois niveaux de difficulté.
- Indications pour guider le joueur.
- Compteur de tentatives.
- Gestion des erreurs de saisie.
- Possibilité de recommencer une partie.

Technologies

- Python 3
- Module random

Installation et lancement

1. Télécharger le repository.
2. Installer Python 3.
3. Exécuter le programme :

python main.py

Objectif pédagogique

Projet réalisé pour approfondir mes connaissances en Python : fonctions, boucles, conditions, paramètres et gestion des exceptions.
